How it was built

The data arrived as three raw CSV files covering seven products. A Python pipeline cleans it and builds the dataset behind both this page and the original Dash app.

  1. Clean

    Pandas keeps only Pink Morsel rows, strips the dollar sign from prices and computes sales = quantity × price for every day and region.

  2. Explore

    A Dash and Plotly app (app.py) charts daily revenue with a region filter. It's covered by a Pytest suite that checks the header, chart and filter render.

  3. Publish

    build_site.py exports the cleaned data for this static page, so the analysis runs in any browser with no server.
